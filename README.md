# dotfiles

Personal dotfiles for macOS terminal setup.

## Quick start

```sh
git clone git@github.com:prateek11rai/dotfiles.git ~/github/prateek11rai/dotfiles
~/github/prateek11rai/dotfiles/scripts/mac-bootstrap.sh
```

## What's included

| Tool | Config |
|------|--------|
| WezTerm | `~/.config/wezterm/` |
| Tmux | `~/.config/tmux/tmux.conf` |
| Starship | `~/.config/starship.toml` |
| Neofetch | `~/.config/neofetch/` |
| Zsh | `~/.zshrc` |
| Zsh plugin | zsh-autosuggestions |

## Theme

We use **Dracula** everywhere. After running the bootstrap, set up Dracula manually in your terminal emulator and other apps.
